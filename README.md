# ChatRabbit 玩具控制套件（使用说明）

品牌到了，云服务停了。这个给孩子的玩具坑点在于闹铃的修改和删除只能通过云来，玩具的物理按键只能增加……
没辙，自己动手改造，把玩具功能还给孩子。

> 目标：**不刷固件**，用家里路由器接管"图灵云"，让玩具的闹钟/音乐/铃声完全由你控制。
> 已验证硬件：杰理 AC791N 玩具（原厂固件 `AC791N_NJ_1V2`），路由器 华硕 BE3600（koolcenter 固件）。
> 最后更新：2026-11-06（服务端 v1.7.3-fix / App v1.10.8）

## 2. 路由器安装（一次性）

1. 路由器后台（`http://192.168.3.1`）→「软件中心」→ 离线安装 → 选 `chatrabbit-1.7.3-fix.tar.gz`
2. 装完在「软件中心」能看到 **ChatRabbit** 图标，点进去是控制台
3. 控制台地址也可直接打开：`http://<路由器IP>:8898/`

安装脚本会自动：
- 装二进制 + 控制脚本 + 网页 + 图标
- 写 `chatrabbit.conf`（端口、时区 `tz_hours=8`、校时 `time_mode=10`）
- 开工开机自启（`init.d`）
- 补齐 **6 个内置铃声**（只补不覆盖）：`alarm_classic / morning / dingdong / urgent / birds / chime`

### 端口占用（已避开 kongke 与华硕自带服务）

| 服务 | 端口 |
|---|---|
| 设备 HTTP（假云，iptables 把设备 80 重定向过来） | 28081 |
| 控制台 / API | 8898 |
| MQTT broker（设备连这个） | 1883（备 24056） |
| SNTP 校时 | 123/udp |

---

## 3. 玩具接入（一次性）

1. 玩具断电重启（或长按配网）
2. 它自己会连 `turingapi.com` → 路由器 DNS 劫持到本机 → 走 MQTT 1883
3. 控制台「状态卡」出现 **✅ 在线** + 设备 IP 即成功
4. 手机 BLE 配网：App → 设备页 →「BLE 配网」（SSID/密码 → 写入玩具）

> 首次接入后玩具时间会在几分钟内自动校准（服务端返回纯文本秒级时间戳）。

---

## 4. 网页控制台（手机也能用）

打开 `http://<路由器IP>:8898/`，自上而下：

| 卡片 | 能做什么 |
|---|---|
| **设备** | 下拉切换多台玩具、刷新、新增、删除（至少保留一台） |
| **状态** | 在线/离线、连接数、上次连接、音量、电量、IP |
| **音乐 / 点歌** | 选文件播放、停止、上传（支持 mp3/aac/wav/m4a/flac/ogg）、删除、刷新 |
| **本机闹钟** | 时间 + 名称 + **星期多选**（每天/工作日/一三五/任意组合/仅一次）+ 铃声 + `wt`，列表可开关/删除/改铃声 |
| **闹铃模式** | 全局默认铃声、响铃时长、试听 |
| **时间** | 设备时间、校时格式（默认纯文本秒）、时区 |
| **日志** | REQ / MQTT / MEDIA / 安装日志、清理坏文件、一键自检、存储占用 |
| **诊断** | `version / sntp_ok / tz_hours / once_mode / audio_cnt / media_cnt` 等 |

## 5. 手机 App

### 5.1 连接
- 设置页填路由器地址（如 `http://192.168.3.1:8898`），或自动发现
- 多台玩具：闹钟页/设备页顶部「设备」下拉切换；设置页「设备管理」可看在线状态与闹钟数

### 5.2 闹钟（纯设备闹钟：手机不响）
| 操作 | 行为 |
|---|---|
| 新建/添加 | 只向设备追加一条（绝不先清空） |
| 编辑 | 原子替换那一条 |
| 删除 | 只删那一条 |
| 清空 | 仅 ⋮ 菜单「清空设备闹钟」+ 二次确认 |
| 重复 | 任意星期组合（位掩码） |
| 仅一次 | 选日期 → 自动算星期位下发；响过 30 分钟后服务端自动删除，**保证只响一次** |
| 铃声 | 每条可独立选（跟随全局 / 6 个内置 / 自己上传的 mp3） |

> 手机端**不会**响铃、不通知、不后台调度；所有闹钟只在玩具上生效。

### 5.3 上传音乐
- 网页和 App **共用同一个目录**（路由器 `/koolshare/chatrabbit/media`，有 USB 时自动迁到 U 盘）
- 上传保留原文件名，同名自动加 `_1`，不会互相覆盖
- 设备只支持 **MP3**（上传非 mp3 会提示）

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 设备离线 | 玩具没连上路由器：检查 DNS 劫持是否生效、1883 是否被占、玩具重新配网 |
| 点歌没声音 | 看控制台「MEDIA LOG」是否有 `GET /media/xxx.mp3`；没有=指令没到设备（QoS/在线）；有=设备播放态被静音（调音量 1~4） |
| 闹钟不响 | ① 设备时钟是否已是当前时间（看「时间」卡）② `wk` 是否选中今天 ③ 看「REQ LOG」有没有设备来取歌 |
| 仅一次不响 | 必须用"日期+星期位"编码（v1.4.8 起服务端自动处理）；`wk=0` 设备永不触发 |
| 改了页面没生效 | Ctrl+F5（浏览器缓存） |
| 日志占空间 | 上限 1MB，超了自动删最旧 |
| 多设备互相干扰 | 每台独立闹钟表/铃声/状态；App 切换后请求自动带 `X-Device-Id` |

## 7. 已知限制（不是 bug）

1. **闹钟写入只能"整表替换"**（固件 optCode 1003），所以"设备侧"永远以路由器表为真源；不要在设备上手动改闹钟后不同步
2. **设备音量只有 0~4**（发更大值会让设备重启）
3. **设备只认 MP3**
4. **时间必须 10 位秒**（毫秒会溢出成 2037 年）
5. **多台设备若在同一 NAT 后同 IP**，HTTP 归属只能靠 `?dev=`（App 已自动带）
6. 原厂云端已停服，所有"云功能"由本机模拟；不要开 OTA（会尝试刷机）
